# BarengSaya Community

BarengSaya Community adalah komunitas belajar bersama yang dibangun untuk mahasiswa yang ingin belajar, berbagi pengetahuan, dan mengembangkan kemampuan melalui kegiatan yang dilakukan secara kolaboratif.

Komunitas ini berfokus pada kegiatan belajar yang bersifat praktis. Materi, contoh project, source code, tugas, dan berbagai hasil pembelajaran dapat dikembangkan dan dibagikan melalui repository GitHub.

## Tentang BarengSaya

Belajar tidak harus dilakukan sendirian.

BarengSaya dibuat sebagai ruang untuk belajar bersama melalui kelas, diskusi, praktik, dan project. Setiap anggota dapat belajar dari materi yang tersedia sekaligus berbagi apa yang mereka pelajari dengan anggota lainnya.

Kegiatan komunitas dapat mencakup berbagai topik, terutama yang berkaitan dengan teknologi dan pengembangan keterampilan mahasiswa.

## Kelas

Kelas di BarengSaya disusun berdasarkan topik yang ingin dipelajari bersama.

Setiap kelas dapat memiliki:

* Materi pembelajaran
* Contoh project
* Source code
* Latihan atau assignment
* Dokumentasi pembelajaran
* Hasil project peserta

Repository yang digunakan untuk setiap kelas dapat ditemukan pada organisasi GitHub ini.

## Repository

Repository di BarengSaya digunakan sebagai tempat untuk menyimpan dan mengembangkan berbagai hasil pembelajaran komunitas.

Struktur repository dapat digunakan untuk:

* Menyimpan materi kelas
* Menyediakan contoh implementasi
* Mengerjakan latihan
* Mengembangkan project bersama
* Mendokumentasikan hasil pembelajaran

Setiap repository memiliki tujuan dan dokumentasi masing-masing.

## Belajar Bersama

BarengSaya tidak hanya berfokus pada materi, tetapi juga pada proses belajar bersama.

Peserta dapat berdiskusi, mengajukan pertanyaan, mencoba implementasi, memperbaiki project, dan berbagi pengalaman dengan anggota lainnya.

Tidak ada tuntutan untuk sudah mahir sebelum bergabung. Yang lebih penting adalah kemauan untuk belajar dan berkembang.

## Kontribusi

BarengSaya terbuka terhadap kontribusi dari anggota komunitas.

Kontribusi dapat berupa:

* Perbaikan materi
* Penambahan contoh project
* Perbaikan source code
* Dokumentasi
* Ide kelas atau topik baru
* Berbagi hasil belajar

Sebelum berkontribusi, silakan membaca `CONTRIBUTING.md` pada repository terkait apabila tersedia.

## Tujuan

BarengSaya dibangun dengan beberapa tujuan sederhana:

1. Membuat kegiatan belajar di kampus menjadi lebih kolaboratif.
2. Membantu mahasiswa belajar melalui praktik dan project.
3. Mendorong mahasiswa untuk membagikan pengetahuan dan hasil belajarnya.
4. Membangun dokumentasi pembelajaran yang dapat digunakan kembali.
5. Menciptakan lingkungan belajar yang terbuka dan saling membantu.

## Mulai Belajar

Jelajahi repository yang tersedia untuk melihat kelas, materi, dan project yang sedang dikembangkan.

Belajar bersama, membuat sesuatu bersama, dan membagikan apa yang sudah dipelajari.
